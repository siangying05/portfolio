RailMate

Smart Rail Route Planner · Flutter Mobile Application

Project Overview

RailMate is a mobile application designed to help users plan journeys across Malaysia's rail network. It brings rail route planning, station transfers, journey guidance and crowd-level estimates into one application using Malaysian government open data.

Developed as an academic project aligned with Sustainable Development Goal 9: Industry, Innovation and Infrastructure.

Key Features

  • Search railway stations and plan routes across LRT, MRT, Monorail, KTM Komuter and KTMB ETS services.
  • Compare journey options, including travel time and number of transfers.
  • View station transfer guidance, including whether a transfer requires exiting the paid area.
  • Estimate train crowd levels using Malaysian rail ridership data.
  • Support user authentication, preferences and trip-related features.

My Contributions

  • Worked on the User Authentication and Preferences module.
  • Implemented registration, sign-in, email OTP and passenger preference functionality.
  • Contributed to the shared mobile application development and integration.

Technologies Used

Project Notes

  • Crowd levels are estimates based on published ridership data, not real-time train occupancy.
  • Payment functionality is simulated for coursework demonstration; no real payment is processed.
  • Route planning uses published timetable and network data.
